# AnyText

**Проводник с читалкой всего для Android.** Любой файл — хоть `.txt`, хоть `.mp3`, хоть `.dolphyplugin` — открывается как текст. Код — с подсветкой синтаксиса. Бинарники — в HEX. Плюс анализ памяти с объёмной диаграммой в стиле WinDirStat.

## Возможности

**Проводник**
- Внутренняя память, Загрузки, Документы, Изображения, Музыка
- **Root-разделы** (`/`, `/system`, `/data`, `/data/data`, `/root`) при наличии su
- Тап по файлу — системный диалог «Открыть через…»: архивы уйдут в WinRAR/7z, медиа — в плееры
- Если файл открыли через читалку AnyText — расширение **запоминается**, дальше такие файлы открываются в ней сразу
- Долгий тап — Поделиться, Копировать путь, Переименовать, Удалить (root-удаление через `rm -rf`)
- Фильтр по имени, недавние файлы с сохранением позиции чтения
- **Анализ памяти**: объёмная круговая диаграмма по папкам (как в WinDirStat), легенда «размер · процент · имя», тап по сектору открывает папку; результат кэшируется (настраивается)
- Единицы размера: ГБ (по умолчанию) или МБ
- Пользовательские ярлыки папок («Быстрый доступ»)

**Читалка / редактор**
- Открывает **любое расширение** как текст (SAF и прямые пути)
- **Подсветка синтаксиса**: Python, JSON, C/C++, Java, Kotlin, JS/TS, C#, XML, HTML, Shell/YAML, SQL, CSS
- **Редактирование** с сохранением в исходной кодировке (UTF-8/16/32, Windows-1251, KOI8-R, ISO-8859-5/1, ASCII; автоопределение + ручной выбор)
- **HEX-режим** (смещение / байты / ASCII) с автопредложением для бинарных файлов
- Поиск с подсветкой совпадений, номера строк, переход к строке
- Статистика: строки, слова, символы, размер
- Большие файлы: порционная догрузка до 16 МБ
- Копирование / «Поделиться» текстом

**Оформление**
- Тёмная и светлая темы, гарнитуры Sans/Serif/Mono, размер шрифта 10–32

## Сборка

1. Android Studio → Open → корень репозитория
2. Дождаться Gradle Sync (Gradle 8.13, AGP 8.11.1, Kotlin 2.2.0)
3. `Build → Build APK(s)` или `./gradlew assembleDebug`

Готовые APK — в [Releases](../../releases).

## Структура

```
app/src/main/java/com/anytext/app/
├── MainActivity.kt          # навигация: home / browse / reader / storage / settings
├── data/Store.kt            # DataStore: настройки, недавние, ассоциации, кэш скана
├── logic/
│   ├── Encoding.kt          # детектор кодировок (BOM, UTF-8 валидация, кириллица)
│   ├── FileLoader.kt        # порционное чтение (SAF + прямые пути)
│   ├── Fs.kt, RootShell.kt  # файловая система + su-оболочка
│   ├── Syntax.kt            # токенизатор подсветки синтаксиса
│   ├── StorageScan.kt       # рекурсивный анализ размеров папок
│   └── HexDump.kt, Utils.kt
├── viewmodel/               # App / Reader / Browse ViewModels
└── ui/                      # manager, browse, reader, storage, settings, theme
```
